This file lists every result page under `docs/experiments/`, newest first, with its topic. `scripts/docs_index.py`
writes the rows from each page's `docs-topic`, `docs-date` and `docs-summary` meta tags and its title, whenever a builder
writes a page; edit a page's tags or lede, never a row here. The pages are Git LFS
files: `git -c lfs.fetchexclude= lfs pull --include="docs/experiments/**/*.html"` fetches them (about 120 MB), and
before that a page opens as a short pointer text. The file in this repository is the source of each page; a claude.ai
artifact, where one exists, is a copy republished to the same URL when the file changes. Each page's footer names the
script that rebuilds it.
