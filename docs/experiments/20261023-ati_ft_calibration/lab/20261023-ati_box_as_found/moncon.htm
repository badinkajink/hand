Thresholding

When Threshold Monitoring is enabled, the Net F/T compares transducer force and torque values to the Threshold Conditions that are turned on. The Output Codes for all true conditions are combined to form the Thresholds Output.

The Units column displays the force or torque counts value in user units. To update the Units column, click Apply.

To save the values, you must click Apply.
Thresholding Settings
When Relay Trigger item Any condition is true is selected, the Thresholds Output is the result of a bitwise-OR operation on valid Output Codes. When All conditions are true is selected, a bitwise-AND operation is performed.
