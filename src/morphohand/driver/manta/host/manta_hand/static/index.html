manual / gantries

Morphology

—

Palm-frame millimetres — the same frame as the plan's mounts and the build sheets. hand_control.py takes firmware mm instead; the resolved firmware target is shown next to each finger so the two never get mixed. Each move runs one axis at a time, like a morphology apply.

Moving a gantry by hand retires the loaded plan's morphology: the fingers stay movable because the rails are still at a known place, but re-apply the morphology before running a plan.
manual / console

Command line

hand_control.py grammar over this connection, so the ports stay with the service. thumb_mcp 30, 0_yaw -5, index_fe1 20, middle_x 42.5, middle_y -40. Comma separated; the whole line is bounds-checked before anything moves.

manual / servos

Finger joints

—

Sim-frame degrees, the frame the plans and the telemetry use. Releasing a slider sends that one joint; every other joint is re-commanded to where it already was, which is what holding still means for a position servo. Ranges are each joint's calibrated limits.

Destructive reference change

Home all six gantry axes?

Clear the hand and watch every rail. Axes home sequentially into their hardstops, and servo joints return to calibrated zero afterwards.

Stop motion cancels a home in progress. The cancelled axis is stopped and de-energised and is not zeroed, so the whole reference is discarded and you will need to home again.
